## Unresolved risks and dependencies

- Live retrieval has not been exercised; the first deployment should attach
  one public https source and record the result. Deployments behind an
  egress proxy must allow public https for citations (OD-19).
- Quotation rights: only a ≤ 1,200-character excerpt, the hash and the URL
  are stored; longer quotation or redistribution needs the publisher's
  terms (OD-08).
- Runs execute inline in the request with a 20 s bound; a hosted provider
  will need the Temporal worker path and its own timeout, retry and cost
  controls before it is enabled.
- The fixture adapter's company extraction is a stand-in; a real adapter's
  output is validated the same way, but its quality is unmeasured.
- Rate limits on attachment and runs are per client address.
