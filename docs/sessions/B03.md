## Delivered

- `@markov/contracts`: catalog contracts (issuers, kinds, statuses, token
  programs, typed catalog prices that exclude `execution_quote`,
  availability with `trade: false`, on-chain mint and verification, snapshot,
  ingestion report, decisions, list/search queries, the Markov issuer feed
  contract v1); operator scopes `ops:catalog:read` and `ops:catalog:write`;
  error code `ADMISSION_BLOCKED`.
- `@markov/catalog` (pure domain): feed parsing that rejects structural
  drift as a whole, per-product sanitisation and validation that rejects
  with every reason, ingestion planning (quarantine, counterfeit symbol,
  mint and duplicate rules, upstream-change pausing, re-quarantine of
  revived records, delisted immunity), SPL Token / Token-2022 mint parsing
  with TLV extensions verified against the program sources and two
  recorded mainnet mints, mint comparison, availability derivation.
- `@markov/issuer-prestocks`: fixture source (synthetic products only,
  refused outside local/test) and a bounded https configured-URL source
  (no credentials, no redirects, 10 s, 2 MiB). The PreStocks-specific
  mapping is BLOCKED (OD-17).
- `@markov/solana-rpc`: bounded `getAccountInfo` (base64).
- `@markov/db`: migration `0002_catalog` (issuer snapshots, instruments with
  unique product and unique live mint, mint verifications, append-only
  decisions with checked statuses) and a store with atomic ingestion,
  keyset pagination, search, guarded status transitions.
- `apps/api`: catalog service and routes: public search and detail (admitted
  and paused only), operator listing in every status, ingestion, mint
  verification, decisions (admit/resume need a `verified` result recorded
  after the last upstream change), snapshots, decision history; audit
  events on every write; `PRESTOCKS_FEED_URL` configuration with https and
  no-credential invariants.
- `apps/cli`: `catalog ingest|list|verify-mint|decide|snapshots`.
- Headless journey (`scripts/ci/startup-check.sh`): operator token, fixture
  ingestion, mint verification against the shared fixture RPC
  (`scripts/dev/fixture-rpc.mjs`, now also used by the web browser tests),
  admission, public search asserting the price kind and `trade: false`,
  refusal of the operator route without a token.
- OpenAPI and the generated client regenerated; docs: `catalog.md` (new),
  `api.md`, `provider-capabilities.md`, `open-decisions.md` (OD-17),
  `threat-model.md`, `operations.md`, `source-register.md`, README,
  `.env.example`; readiness baseline for `catalog.prestocks.ingest`.

## Limitations and unresolved risks

- No real PreStocks product exists in any catalog produced here; fixtures
  are synthetic and labelled. Enabling `configured_url` ingestion requires
  OD-17 and a terms review recorded as decision evidence.
- Token-2022 extension compatibility (fees, hooks, delegates, pausing) is
  recorded, not evaluated; B04 must decide what is tradeable.
- Search is prefix/substring matching on symbol, name and company; no
  ranking or fuzzy matching.
- Scheduled re-ingestion and issuer change alerts belong to B16.
