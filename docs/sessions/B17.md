## Delivered

- Provider decision (product owner, 2026-09-25): the AI and agent side
  uses the xAI Grok API. `packages/model-xai` implements both model
  contracts over the OpenAI-compatible chat completions endpoint without
  a provider SDK:
  - `createXaiClient`: bearer authentication, `https` required outside
    local/test, no redirects, a timeout, a 1 MiB byte cap, classified
    failures (`unauthorized` 401/403 not retryable, `rate_limited` 429
    and `http` 5xx retryable, `oversized`, `malformed`, `unreachable`),
    the key redacted from every error, usage priced in micros per token
    from configured rates.
  - `createXaiResearchAdapter`: sends the canonical prompt text the run
    hashes for provenance verbatim, asks for one JSON object, validates
    it and keeps only the run's own source ids and candidate instrument
    ids as bounded plain text; a reply that is not the protocol fails the
    run (nothing is invented).
  - `createXaiCompanionAdapter`: one JSON step per call (a tool call or
    the answer); prose is treated as the answer and can never become a
    call; the loop still validates every tool, argument and citation.
- Configuration: `RESEARCH_MODEL_PROVIDER` and `COMPANION_MODEL_PROVIDER`
  accept `xai`; `XAI_API_KEY` (required by, and refused without, a

  `XAI_TIMEOUT_MS`, `XAI_INPUT_MICROS_PER_TOKEN`,
