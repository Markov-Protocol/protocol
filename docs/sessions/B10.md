## Unresolved risks and dependencies

- A live route (OD-21) is the gate before any execution outside fixtures:
  current documentation, a gateway or adapter for the build contract, a
  recorded live quote and build, the route programs reviewed into the
  matrix. Until then a live plan fails closed at the quote.
- Priority fees follow the plan's cap without a fee-market estimate;
  versioned messages with lookup tables are decoded and validated but no
  live route has exercised them; a devnet buy and sell with recorded
  signatures and fills is the next evidence step.
- The fixture chain models system transfers, compute budget, idempotent
  associated-token creation and token transfers; other token instructions
  fail there by design (the validator refuses them anyway).
- Read-time reconciliation on status reads calls the node (throttled to
  2 s per attempt) and the worker loop calls it every 5 s per live attempt;
  both are bounded but not yet rate-shaped for many concurrent attempts.
- Multi-constituent plans stay staged and unexecutable until B11; the
  outbox is written but nothing publishes it until B18.
- The demo key file (`--keep-key`) exists for the headless check only; it
  is written into a temp directory the check removes.
